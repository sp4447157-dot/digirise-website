HOW TO EDIT:
1. Extract the ZIP.
2. Open HTML files in a code editor (for example, VS Code or a simple text editor).
3. Search for placeholder text like [Add your business email] and replace it.
4. Edit colors near the top of assets/style.css under :root.
5. Replace the PDF file in assets with your final ebook, keeping the same filename.
6. Test all pages on mobile before publishing.
